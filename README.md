# CodeAlpha Random Quote Generator

A simple and responsive Random Quote Generator created as part of my CodeAlpha Internship.

## Features

- Generates random quotes
- Displays the quote author
- New Quote button
- Copy Quote functionality
- Prevents immediate quote repetition
- Responsive design
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Click the "New Quote" button to generate different quotes.
